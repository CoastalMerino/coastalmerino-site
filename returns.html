How returns and exchanges work.

Return window

Decision neededHow many days after delivery a polo can be returned (30 days is the most common in premium apparel).

Condition

Decision neededUnworn with tags only, or also worn once? Many golf brands only accept unworn, unwashed items with tags attached.

Exchanges

Decision neededFree size exchanges, or treat an exchange as a return plus a new order? Who pays return shipping?

Refunds

Decision neededRefund to the original payment method, how many days after the return arrives, and whether shipping costs are refunded.

How to start a return

Email hello@coastalmerino.com with your order number and what you'd like to send back. We'll reply with next steps.
